NARUTOCORE
Guide d'utilisation — Système de chakra & jutsu pour serveur RP
Version 0.1.0 • 54 jutsu • Minecraft Paper 1.21.8

NarutoCore ajoute un système de combat ninja : chaque joueur a une réserve de chakra, une affinité élémentaire, un clan (Kekkei Genkai) et un rang. Les techniques (jutsu) s'obtiennent sous forme de parchemins et se lancent d'un clic droit.

1. Installation

  • Serveur Paper 1.21.8 (Java 21).
  • Place le fichier NarutoCore-0.1.0.jar directement dans le dossier plugins/ (pas le dossier de code source).
  • Redémarre le serveur. La base plugins/NarutoCore/naruto.db est créée automatiquement.

2. Première connexion

Un menu s'ouvre pour choisir ton affinité (Katon, Suiton, Fūton, Doton, Raiton) puis ton clan. Une barre de chakra apparaît en haut de l'écran (elle se recharge toute seule).

3. Obtenir et lancer un jutsu

  1. Tape /jutsu : le menu affiche les techniques de ton élément et ton rang.
  2. Clique une technique → tu reçois un parchemin (item) dans ton inventaire.
  3. Tiens le parchemin en main et fais un clic droit pour lancer le jutsu.
Constitue-toi une barre d'action avec tes parchemins préférés. Chaque jutsu coûte du chakra et a un temps de recharge (indiqués sur le parchemin). Vise ce que tu veux toucher : la plupart des techniques ciblent l'entité ou le point que tu regardes.

7. Commandes

CommandeEffet
/ninjaTon profil (élément, clan, rang, chakra, XP).
/jutsuMenu des jutsu (clique = reçois le parchemin). /jutsu <id> lance directement.
/chakraAffiche ton chakra. /chakra full (op) recharge.
/narutoadmin(Op) element|clan|rank|chakra|reset <joueur> [valeur]

Exemples admin

  • /narutoadmin rank Zazou KAGE — débloque tous les jutsu.
  • /narutoadmin element Zazou RAITON — change l'affinité.
  • /narutoadmin chakra Zazou full — recharge le chakra.
  • /narutoadmin reset Zazou — réinitialise le profil.

8. Bon à savoir

  • Le chakra se régénère automatiquement — gère-le comme une ressource en combat.
  • Fais-toi une barre d'action de parchemins : offensif + mobilité + protection (mur, Kawarimi).
  • Les jutsu de zone (Messhitsu, Daibakufu, Kirin) touchent plusieurs ennemis autour du point visé.
  • Les jutsu armure (feu/terre/foudre) et Kai sont défensifs/utilitaires.

9. À venir

  • Progression : XP, montée en rang, apprentissage de jutsu, missions, villages.
