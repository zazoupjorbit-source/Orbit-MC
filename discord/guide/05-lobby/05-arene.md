**Où** : lobby, monde `arene`, PNJ dans la salle d'arcade. Pack sur le port 8797. Permission admin : `orbitarene.admin`. Docs : `plugins-src\OrbitArene\docs\`.

**▸ Les jeux**
• **Nébuleuse** : on grossit en absorbant (mode « .io »), ou mode comète.
• **Charge Nova** : arène à charges explosives.
• **Palet Orbital** : air hockey.
• **Turbo-Sphère** : mini foot en véhicules.
File d'attente et **bots** quand il manque des joueurs.

**▸ Commandes joueurs**
`/arene jouer <jeu> [mode]` · `/arene quitter` · `/arene rejouer` · `/arene top <jeu>`

**▸ Commandes admin**
`/arene admin parties` (parties en cours) · `/arene admin pnj` (repose les PNJ) · `/arene admin stop` (arrête les parties)
