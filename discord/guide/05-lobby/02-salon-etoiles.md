**Où** : aile est du casino (arche dans le mur est), plugin OrbitCasino. Doc : `plugins-src\OrbitCasino\docs\salon-des-etoiles.md`.

**▸ Les jeux**
• **Crash** (écran HD) : le multiplicateur monte, il faut encaisser avant le crash. Plafond ×100.
• **Mines** (écran HD) : cases à retourner sans tomber sur une mine. Gain max 100 000 OC.
• **Plinko** : billes qui tombent entre des picots.
• **Roue des Étoiles** : 25 cases.
• **Billard** : visée au regard, accroupi pour la force ; solo, contre un bot, ou défi à 2 avec mise (sans commission).
• **Jukebox** (comptoir du bar) : disques vanilla, file d'attente et votes.
Les blocs des jeux sont incassables, même en créatif ; la table de billard se répare seule.

**▸ Commandes**
`/cj <crash|mines|roue|jukebox|billard> [action]` — actions des boutons du chat (ex. `/cj crash miser`, `/cj crash encaisser`, `/cj billard rejoindre`, `/cj billard quitter`). Règles : `/oc regles <jeu>`.
