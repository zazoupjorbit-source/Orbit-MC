**Où** : lobby, monde `bornes`, PNJ dans la salle d'arcade. Pack sur le port 8796. Permission admin : `orbitbornes.admin`. Docs : `plugins-src\OrbitBornes\docs\`.

**▸ Les jeux**
• **ASTROBLOCS** : blocs qui tombent, solo ou **duel**.
• **CRISTAUX D'ORBIT** : match-3 en écran HD.
• **DÉFENSE ORBITALE** : tir spatial.
• **PULSAR** : jeu de rythme.

**▸ Commandes joueurs** (`/bornes`, alias `/borne`)
`/bornes jouer <jeu> [mode]` (ex. `astroblocs solo`, `astroblocs duel`) · `/bornes rejouer` · `/bornes top <jeu>` · `/bornes quitter` · `/bornes reprendre`
